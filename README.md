# 🏛️ Architecture & Interior Design Website

A modern and responsive website designed for showcasing architecture and interior design projects. This project focuses on clean UI, smooth layout, and professional presentation of creative work.


## 📌 Features

- Modern and elegant landing page
- Architecture & interior design showcase
- Project gallery section
- Services section
- About and Contact pages
- Fully responsive design (mobile, tablet, desktop)
- Clean and structured UI
- Fast loading and lightweight



## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript 
- Bootstrap
